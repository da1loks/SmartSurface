# Arduino: управление и одометрия

Протокол описан в предоставленной технической документации. Он относится к `motor_bridge_node`; старые презентационные описания могут использовать другой формат.

## Последовательный обмен

Команды ASCII завершаются переводом строки. В документации моста указана скорость 115200 бод; это значение нужно согласовать с прошивкой Arduino. Скорость UART лидара является отдельным параметром.

- `M:vy,vx,vt`: три компоненты команды движения после преобразования осей.
- `R`: запрос счётчиков энкодеров.
- `O:e1,e2,e3,e4`: ответ Arduino с четырьмя счётчиками.
- `S:angle`: команда серво.
- `L:r,g,b,brightness`: цвет и яркость LED.
- `E`: команда при завершении моста; её действие следует проверить в прошивке.

В заметках порядок колёс указан как FL, FR, RL, RR. Порядок подключения моторов и энкодеров должен совпадать с этим соглашением.

## Преобразование осей

В описании моста `arduino_vy = ROS vx`, `arduino_vx = -ROS vy`. В описании некоторых сценариев движение вперёд задаётся отрицательным `linear.y`. Поэтому нельзя переносить команды между UI, сценарием и прошивкой без проверки знаков на реальном роботе.

Цикл управления описан с частотой 20 Гц. Параметры рампы ограничивают изменение скорости; `instant_linear_velocity` может отключать рампу линейной компоненты. Мёртвая зона поворота подавляет небольшую ненулевую угловую команду.

## Колёсная одометрия

Для приращения энкодера Δe, числа импульсов на оборот N и радиуса колеса r путь колеса равен `d = Δe / N × 2πr`.

Далее кинематика mecanum преобразует пути четырёх колёс в перемещение и поворот корпуса. Мост переводит оси Arduino в ROS и интегрирует движение с учётом текущего курса. Полные формулы приведены в [исходном техническом документе](../ROBOSURFACE_FULL_TECHNICAL.md).

На оценку влияют радиусы колёс, геометрия платформы, число импульсов, направление счёта, проскальзывание и люфт. EKF сглаживает оценку; без внешней привязки колёсная одометрия продолжает накапливать ошибку.
